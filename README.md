# OBE Learning Portal — GitHub + Google

No Firebase, Python, passwords, SDK or backend. This is a public navigation website, not a standalone LMS. Google Classroom and Google sharing permissions protect private content. The links in config.js are PUBLIC even when displayed under Admin or Teacher. Never put credentials, student data, invitation codes, private meeting links or confidential records in the repository. For sensitive resources leave the corresponding config blank and use the Google service home page directly; distribute restricted links privately.

## 1. Create Google Classroom
Go to https://classroom.google.com/ and create a class named Outcome Based Education (if your account allows class creation). In Classwork create topics: Pre-course, Module 01 through Module 10, Final Examination. Create materials and assignments under each. Keep orientation and exam as drafts until ready. Invite teachers and approved students through People. Google account/domain restrictions may apply; test with one external learner. Copy the class URL from the browser, not an invitation link or class code. Put it in `classroom` in config.js. Teachers and admin can use Classroom home. Course owner handles administration; Classroom does not offer a separate independent admin role for personal accounts.

## 2. Create registration form
Go to https://forms.google.com/ and create OBE Course Registration. Add required name, email (use verified email collection if appropriate), institution and consent to course communications. Publish and copy responder link into `registration`. In Responses link to a Sheet; keep it private. Enable response receipts if email collection and your settings allow. Otherwise send approval/invitation manually. Registration does not automatically enroll a student. Review responses and invite the student using Classroom People. Do not ask for passwords.

## 3. Learning resources and assessment
Upload videos, PDF, PPT, PNG and JPG to Drive and attach to Classroom posts with appropriate permissions. Use Forms quizzes for automatic scoring where appropriate; Classroom assignments for descriptive answers. Publish final exam when ready; administrator/course owner evaluates it. Do not publish answer keys or exam links on the public website. Optional module links in config.js should only be used for resources intended to be public or whose access is restricted independently. Leave blanks if not needed. Module topics are not supplied; fill titles as you develop them.

## 4. Live, feedback, doubts and certificates
Create a Meet session and distribute its link privately in Classroom; leave `live` blank unless the session is intended to be public. Create separate Forms for doubts, confidential feedback and certificate requests. Paste responder links in `doubt`, `feedback`, `certificate`. Keep feedback Form editor access and response Sheet restricted to the owner, not teachers. Do not promise anonymity if collecting email. Create individual certificates in Docs or Slides, export PDF, share only with the recipient via Drive or email. No automatic certificate generation. Maintain attendance and final results in private Sheets; Classroom grades provide individual assessment results. Video engagement is not tracked. Attendance is manual. Teacher permissions are Classroom's built-in roles, not custom granular controls.

## 5. Configure and deploy
Edit config.js only. Replace empty strings with appropriate HTTPS links; keep quotes and commas. No API key. Empty links show Not configured. The site works without configuration, but cannot connect to resources you have not created. For private Sheets use Google Sheets home or bookmarks instead of publishing their links. Open index.html locally to preview. Upload index.html, style.css, app.js, config.js, .nojekyll to a new public GitHub repository (recommended name obe-learning, without trailing dot). Settings > Pages > Deploy from a branch > main > /(root) > Save. Wait for deployment and open the Pages URL. If reusing the old repository, replace index.html and remove old Firebase scripts/config/rules from the deployed branch; rotate the previously exposed password and remove sensitive URLs from history where possible. No password forms are included in this version.

## 6. Acceptance test
Open website on desktop/mobile. Check navigation, theme, registration link. Submit test registration; check private Sheet and email receipt if enabled. Invite test student, accept invitation, access class and submit assignment. Invite teacher, grade assignment. Verify student cannot open private admin Sheet or feedback responses. Test final exam and privately share a certificate. Remove test accounts if desired. External Google services must be configured by you; this package cannot create them or verify live access.
